
# Digital Gram Panchayat Services

A web-based portal designed to digitize Gram Panchayat services and make them accessible to citizens.

## Features
- Citizen Registration and Login
- Birth Certificate Applications
- Death Certificate Applications
- Other Certificate Requests
- Tax Payment Interface (Demo)
- Welfare Scheme Applications
- Grievance Registration and Tracking
- Citizen Dashboard
- Staff/Admin Dashboard

## Technologies Used
- HTML
- CSS
- Java
- Firebase Cloud Firestore
